# Resume Designer

ИИ-помощник для составления резюме, встроенный в мессенджер.

**Статус:** начало проекта, ~1 неделя работы. На демо 28.07 рассказываем идею и план — без показа кода.

Проект допуска в колледж · СберТех (GitVerse + GigaChat)

---

## Какую проблему решаем

Студенты и выпускники Чувашии часто не умеют составлять резюме: текст без структуры, без акцента на достижения, не под целевую должность. Из-за этого сложнее найти работу, регион теряет молодые кадры.

## Как решаем

**Resume Designer** — цифровой инструмент в мессенджере. Пользователь пишет сообщение, система с помощью GigaChat даёт рекомендации: как улучшить резюме, что добавить, как сформулировать опыт.

Схема работы:

```
Пользователь (мессенджер)
        ↓
  Сервис Resume Designer
        ↓
      GigaChat
        ↓
  Ответ с рекомендациями → пользователю
```



## Функционал



### ИИ-конструктор резюме (основной)

- создание резюме с нуля через диалог;
- анализ уже готового резюме;
- персональные рекомендации по улучшению.

**Подход к улучшениям**

- Опираемся на стандартную структуру резюме, принятую на HeadHunter (HH): контакты, цель, ключевые навыки, опыт (по местам/проектам), образование, доп. информация — это формат, к которому привыкли рекрутеры.
- При доработке опыта фокусируемся на результатах: просим и оформляем достижения через метрики и влияние на KPI (числа, проценты, показатели эффективности).
- Процесс включает короткое «интервью от ИИ» — если в резюме мало данных о вкладе или метриках, ассистент задаёт 2–3 целевых вопроса, собирает ответы и затем формирует улучшенный черновик «Опыт».

## Demo-site (сайт‑визитка)

- Добавлена простая демо‑страница, доступная по пути `/site` при запущенном сервисе. Она отправляет запросы к API и показывает ответ.
- Чтобы запустить локально, используйте один из вариантов:

```bash
# Запуск через Uvicorn
uvicorn app.main:app --reload

# Или через Docker Compose
docker-compose up --build
```

- Примечание: пока учётные данные GigaChat не выданы, сервис работает в `stub`-режиме и возвращает демонстрационное сообщение-заглушку вместо реального ответа модели.
